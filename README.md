# muse-stage（試作）

ビジコンの発表で、Mac版ミューズアプリ（Muse.app）の横に並べて起動する、出力専用の相方アプリです。
VRM のミューズを大きく表示し、ミューズの返事のテキストを読み上げながら口を動かします。

- 指示書: neta-cho `tasks/claude-code/2026-11-10-muse-stage-tauri-prototype.md`
- GitHub: oosawak/muse-stage-prototype（実行用の置き場所は Mac の ~/Workspace の下）

## 起動

ビルド済みのアプリ:

```
open "src-tauri/target/release/bundle/macos/Muse Stage.app"
```

作り直すとき（Node と Rust が要る）:

```
npm install
npx tauri build --bundles app   # アプリを作る
npx tauri dev                   # 開発用に起動（画面の変更がすぐ反映される）
```

## 使い方

1. Muse.app で会話する（音声入力ボタンで話す）
2. ミューズの返事をコピーして、muse-stage の右下の欄に貼る
3. 「読み上げ」（またはスペースキー、欄の中なら ⌘Enter）で、ミューズが読み上げて口が動く。字幕も出る
4. 舞台では両方のアプリを最大化（全画面）にして、3 本指スワイプで行き来する
   - 全画面：「全画面」ボタンか F キー。止める：Esc
   - 右下の操作パネルは、ふだんは薄く、マウスを動かすと濃くなる

### 読み上げのしくみ（右下の選択）

- 自動（初期）：アプリ内の WebView の speechSynthesis を使い、1.5 秒たっても始まらなければ macOS の `say` に切り替える
- WebView の speechSynthesis だけ／macOS の say だけ、にも切り替えられる。say の声は Kyoko が初期

### Muse.app から自動で取り込む（実験・第2段）

「Muse から取り込む」で、Muse.app の画面の文字をアクセシビリティ経由で読み、いちばん新しい返事を欄に入れます。
「新しい返事を自動で読む」を付けると、2 秒ごとに見て、新しい返事が出たら読み上げます。

使うには、システム設定 → プライバシーとセキュリティ → アクセシビリティ で「Muse Stage」を許可してください（未許可のままでは読めません）。エラー文で osascript が名指しされる場合は、`/usr/bin/osascript` も同じ一覧に追加して許可してください。

読み取り方式についての実機知見（2026-11-14）: Muse.app では `entire contents` が常に 0 件を返すため、子要素（UI elements）をレベルごとにたどる幅優先で AXStaticText を集めています。会話メッセージには2つの姿があります。古いものは「ユーザーメッセージ: 」「アシスタントメッセージ: 」の接頭辞つきで1要素に全文が入りますが、新しいものは段落・コード片ごとにバラバラの要素に分かれ、接頭辞がありません（ユーザーの発言だけ先頭に「自分:」の断片が付きます）。そのため要素の経路も一緒に集め、会話リストの子ごとに断片を組み立て直しています。接頭辞だけを探すと最新の返事を逃します。また、画面に見えている範囲しかツリーに載らないため、取り込み前に Muse.app で一番下までスクロールしておくと新しい返事が載ります。幅優先の走査には時間がかかるため、取り込みには十数秒かかることがあります。

## Web版と「中継の合言葉」

Web版（ブラウザで開く版）は、アプリ版と違ってミューズからのファイルを直接受け取れないので、返事は公開MQTT中継で届きます。そのとき「どの舞台に届けるか」を決めるのが、**中継の合言葉**です。設定は、使う人が自分で行います。

1. **合言葉は、使う人が自分で適当な文字列を作ります**（他人と被らない、長めの文字列がおすすめです）
2. **舞台のパネルで設定します**：「Web直送（MQTT中継）」にチェックを入れ、その下の「中継の合言葉」の欄に、その文字列を入れます（アプリ版・Web版とも同じ欄です）
3. **ミューズ側では、同じ文字列を決まったファイルに置きます**：`~/workspace/stage-relay-topic.txt`。送信スクリプト（`tools/send_reply_mqtt.mjs`）は、そこから合言葉を読みます
4. **ミューズへの指示書には、合言葉そのものは書きません**。「合言葉はそのファイルから読む」という決めだけを書きます。合言葉の値は、チャットやこのリポジトリには出さないでください
5. **文が届くのは、同じ合言葉を設定した同士だけです**。合言葉が違う舞台には届きません

### Web版の同梱スライド（デモ用）

Web版の置き場所に `slides/manifest.json` があると、開いた時点でそのスライドが読み込まれます（アプリ版には影響しません）。形式:

```json
{
  "title": "資料の名前",
  "slides": ["slides/pitch/slide-01.png", { "src": "slides/movie.mp4", "type": "video" }],
  "links": { "11": [{ "x": 0.055, "y": 0.375, "w": 0.89, "h": 0.125, "url": "https://example.com/", "label": "表示名" }] }
}
```

- `slides`: 画像はURLの文字列。動画（MP4など）は `{ "src": ..., "type": "video" }` と書くと、スライドの1枚として再生できます
- `links`（任意）: ページ番号ごとに、画像の割合（x・y・w・h）で指定した透明なリンク領域を重ねます
- アプリ版・Web版とも、「スライドを選ぶ」で動画ファイルを選んでも動画スライドになります

```
MUSE_SELFTEST=1 "src-tauri/target/release/bundle/macos/Muse Stage.app/Contents/MacOS/muse-stage"
```
